# KAT GTFS Archive

This repo is inspired by Simon Willison's initial 2020 blog post on Git Scraping: https://simonwillison.net/2020/Oct/9/git-scraping/

What this repo does are two things:

1. Take a snapshot of the GTFS-RT feed of Knoxville's Knoxville Area Transit (KAT) public transportation system.
2. Record the changes of the feed overtime using Git

## Motivation

Storing data can be pretty expensive! Is there a way to more cheaply store it?

Git scraping is a possible answer.

Run some commands using Github Actions and record the changes. Let it run, and that's it.
